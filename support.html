A good first five minutes

  1. Add your first links. Use + to add an HTTP/HTTPS URL, drop a browser link into a collection, or import a browser bookmark HTML export.
  2. Make a place for each interest. Create collections and nested folders, then add notes and keywords to help you find items later.
  3. Read beside your library. Select a bookmark to open its page alongside the list. Use Open in Browser for a normal browser window.
  4. Follow a feed. Switch to Feeds, add a supported RSS or Atom feed, and organize subscriptions into folders.
  5. Keep a bookmark backup. In Settings → Backup & Restore, choose Back Up Library before a reset or moving to another Mac. Keep the complete backup folder.

Updating Alfolio

  1. Before updating, choose Alfolio → Quit Alfolio from the menu bar, or press ⌘Q. Closing the window with the red button does not quit the app.
  2. Open TestFlight or the App Store and install the update.
  3. Open Alfolio after the installation finishes.

If the update could not be completed, quit Alfolio completely and retry. If it still fails, contact support with the exact error message, your macOS version and the Alfolio build number. Remove personal information from screenshots.

Frequently asked questions

Why is a thumbnail missing or showing a site icon?

Alfolio tries to use a photo from the page, then a page-provided sharing image. If no usable photo is available, it can show a compact site icon. Open the page and choose the picture button in its preview toolbar to try the current page image. Sites that require authentication, build their content dynamically or block image requests may not provide a usable thumbnail.

Why does a website not load or sign in?

Check that the original URL opens in your normal browser. Website sign-in links can open a separate Alfolio web window; cookies are shared with the preview. Some authentication methods and sites may not support embedded browsers. Use Open in Browser in that case. Alfolio is not affiliated with the websites you visit and cannot recover their accounts.

Does closing a website window sign me out?

No. Use the website’s own sign-out action. A website may keep its session in the app’s cookies after a window closes or the app restarts. Safari and Chrome use separate sessions. Alfolio currently has no control that clears all cookies and site storage.

Why was a dropped or imported link skipped?

A duplicate URL may already exist in the library. Search for the URL before importing it again. Browser bookmark imports use HTML bookmark exports, not a browser profile database. Links must use HTTP or HTTPS.

Are items in Broken Links deleted automatically?

No. A reachability check can fail because of authentication, a temporary outage, rate limiting or a website blocking automated requests. Open the item to verify it and recheck if needed. Deleting broken links requires confirmation.

Can I use the library offline?

You can browse locally stored bookmark records and available saved feed content. Loading websites, fetching page information, downloading uncached images and refreshing feeds require a network connection. Alfolio does not archive every website for offline use.

How do I switch language, appearance or list layout?

Open Settings for language and theme controls. Use View to change list, card and other collection layouts. The sidebar button at the upper left hides or shows the sidebar, and the adjacent New Window button opens another workspace.

What does a library backup include?

The current backup contains bookmarks, collections and tags. It does not include feed subscriptions or articles, website cookies, signed-in sessions, local documents or all appearance settings. A Chrome-compatible HTML export is also available for bookmarks. Keep backup folders private because Alfolio does not encrypt them.

What does Reset All Data remove?

It clears bookmark, collection and tag records and app preferences. It is not a full profile wipe: feeds, website cookies, cached images and exported files can remain. Make a backup first. Contact support before removing the app’s profile if you need complete removal.

Where are the open-source licenses?

In the app, choose Help → Open Source Licenses, or use the license link in Settings. Original dependency, Electron and Chromium notices are included with the application.

Tell us what happened

For a reproducible issue, include the app version, macOS version and a short sequence of steps. If only one public website fails, include its URL. A redacted screenshot or the exact error text is helpful.

Contact Folio Grove

Email is the support channel for Alfolio. You can also use it for privacy questions or to request instructions for removing a local profile. No Alfolio account is required.

Contact Folio Grove at foliogrove.app@gmail.com.

Support cannot access your Mac, recover an unbacked-up library, or reset an account belonging to another website. Website account and transaction questions should go to that website’s provider.

About Alfolio

Alfolio is a local bookmark and feed workspace for Mac, made by Folio Grove. Some editions also offer browsing of a local document folder you select. Available controls can differ by edition and version.

For data handling, website requests, cookies, backups and deletion, read the Privacy Policy. Open-source license notices are available inside the app.
